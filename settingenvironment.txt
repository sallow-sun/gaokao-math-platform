## 5. 检查 Python 是否安装

在 VS Code 顶部点击：

```text
终端 → 新建终端
```

在下方终端输入：

```bash
python --version
```

如果显示类似：

```text
Python 3.13.5
```

说明已经安装。

如果提示找不到 `python`，再输入：

```bash
py --version
```

如果两个命令都不能运行，就需要先安装 Python。

安装 Python 时必须勾选：

```text
Add Python to PATH
```

## 6. 创建虚拟环境

在 VS Code 下方终端中输入：

```bash
python -m venv venv
```

如果 `python` 命令不能使用，就输入：

```bash
py -m venv venv
```

运行完成后，项目中会多出一个：

```text
venv
```

文件夹。

目录会变成：

```text
login-system
├─ venv
├─ app.py
├─ requirements.txt
├─ templates
└─ static
```

不要修改 `venv` 里面的文件。

## 7. 启用虚拟环境

如果你的终端是 PowerShell，输入：

```powershell
venv\Scripts\Activate.ps1
```

如果出现权限错误，例如：

```text
无法加载文件，因为在此系统上禁止运行脚本
```

先执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

然后再执行：

```powershell
venv\Scripts\Activate.ps1
```

成功后，终端前面会出现：

```text
(venv)
```

例如：

```text
(venv) PS C:\Users\你的用户名\Desktop\login-system>
```

如果终端是 CMD，则输入：

```cmd
venv\Scripts\activate
```

## 8. 选择 Python 解释器

按快捷键：

```text
Ctrl + Shift + P
```

输入：

```text
Python: Select Interpreter
```

选择带有下面内容的解释器：

```text
venv
```

通常路径类似：

```text
.\venv\Scripts\python.exe
```

这一步很重要，否则 VS Code 可能会提示找不到 Flask。

## 9. 安装 Flask

确保终端前面有 `(venv)`，然后输入：

```bash
pip install -r requirements.txt
```

也可以直接输入：

```bash
pip install flask
```

安装完成后，可以检查：

```bash
pip show flask
```

如果显示 Flask 的版本信息，说明安装成功。

## 11. 运行后端

在 VS Code 终端输入：

```bash
python app.py
```

或者：

```bash
py app.py
```

运行成功会显示类似：

```text
 * Serving Flask app 'app'
 * Debug mode: on
 * Running on http://127.0.0.1:5000
```

按住 `Ctrl`，点击终端中的：

```text
http://127.0.0.1:5000
```

也可以手动在浏览器输入：

```text
http://127.0.0.1:5000
```

注意不要直接双击打开 `login.html`，因为这个网页需要 Flask 后端提供服务。

错误的打开方式是：

```text
file:///C:/.../login.html
```

正确地址是：

```text
http://127.0.0.1:5000
```

## 14. 停止网站

在正在运行 Flask 的终端中按：

```text
Ctrl + C
```

就会停止服务器。

修改 Python 代码后，通常 Flask 会自动重新加载。

如果没有自动重新加载，就先按：

```text
Ctrl + C
```

然后再次运行：

```bash
python app.py
```

## 15. 常见错误

### 找不到 Flask

错误类似：

```text
ModuleNotFoundError: No module named 'flask'
```

执行：

```bash
venv\Scripts\Activate.ps1
pip install flask
```

并确认 VS Code 选择的是 `venv` 解释器。

### 找不到 templates

错误类似：

```text
TemplateNotFound: login.html
```

检查结构必须是：

```text
templates/login.html
```

不能写成：

```text
template/login.html
```

也不能把 `templates` 放在其他文件夹中。

### CSS 没有效果

检查 CSS 路径：

```text
static/css/style.css
```

HTML 中应写：

```html
<link
    rel="stylesheet"
    href="{{ url_for('static', filename='css/style.css') }}"
>
```

不要直接写本地绝对路径。

### 页面无法访问

确认终端中的 Flask 还在运行，并访问：

```text
http://127.0.0.1:5000
```

不要访问：

```text
http://127.0.0.1:5500
```

`5500` 通常是 Live Server，它无法正常运行这个 Flask 项目。
