# 试卷打印版式

以项目提供的《如何制作一份高考数学原版试卷？ - 知乎.pdf》为排版参考：第 5～8 页的纸张、字体与卷头，第 9～15 页的题型说明、题号、选项和解答题，第 16 页的公式字号。文章给出的是一种原卷制作示例，各地区、年份并非完全相同。

- 新建组卷默认 16 开（185 × 260 mm）；原有草稿及分享快照继续使用各自保存的纸张，也可选择 A4。
- 上下边距 20 mm、左右 22 mm，页脚距下边缘 15 mm。正文和公式基准 10.5 pt，正文 1.5 倍行距；中文宋体、英文 Times New Roman，题型说明与科目黑体。题目中的材料仍用楷体。
- 卷头显示用户设置的标题、数学、动态页数/题数/总分及简洁作答说明，不自动添加官方考试名称、密级或未经设置的考试时间。
- 客观题使用两字悬挂缩进。选项按实际宽度自动选择四列、两列或单列，长选项在列内换行；解答题题号和分数独占一行，题干首行缩进，小问保持层级。
- 同题型客观题分值一致时，只在题型说明显示每题分值；分值不一致时逐题显示。解答题始终逐题显示分数。多选题不擅自生成部分得分规则。
- 保留自定义答题留白和另起一页。题型标题与题干一起分页，公式、配图和文字行避免截断。工作区、测量区和打印区共用卷头组件与样式。

入口：`PaperBuilderView.vue`；卷头：`PaperHeading.vue`；题目/分数组装及分页辅助：`paperLayout.js`；卷面样式：`paper-builder.css`。

验证命令：在 `frontend/` 运行 `npm test`、`npm run lint`、`npm run build`，然后运行 `node tests/exam-print.browser.test.cjs` 和 `node tests/paper-builder.browser.test.cjs`。Windows Chrome 可通过 `CHROME_EXECUTABLE` 指定。专用回归生成 `.tmp/exam-16k.pdf`、`.tmp/exam-a4.pdf`，覆盖 19 题/150 分、四种题型、三种选项布局、边距及页码避让；既有组卷回归覆盖超长题、配图、拖动、撤销和打印。

打印建议使用 100% 比例并关闭浏览器自带页眉页脚。浏览器采用 KaTeX 和系统字体，跨系统字体回退可能产生细微差异，不能等同于 Word/MathType 的逐像素复刻。本次只更新显示模板，不修改题目内容、分数或已核验快照；历史快照也会使用新模板显示。
