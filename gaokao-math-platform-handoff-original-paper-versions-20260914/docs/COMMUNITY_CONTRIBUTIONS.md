# 社区贡献

个人主页的社区贡献标签显示题目投稿和纠错反馈，支持类型、状态筛选与分页。本人可查看待处理记录及处理说明；访客只看到仍公开的已采纳题目和已解决反馈，不返回描述、建议、审核说明或未公开题干。

上传题目入口为 /contribute，第一版支持填写文字与公式题干、答案、解析。登录用户提交后创建初审草稿，通过现有管理员审核流程发布。贡献归属原投稿者，而非操作发布的审核员。重复内容提交返回已有记录，每位用户每天最多投稿20题。

API：GET /api/v1/users/{id}/contributions；GET /api/v1/users/me/contributions/{kind}/{id}；POST /api/v1/users/me/contributions。详细记录接口校验所属用户，写入接口要求登录及 CSRF 校验。

第一版不含解法投稿、文件/配图导入、贡献积分或排行榜。
