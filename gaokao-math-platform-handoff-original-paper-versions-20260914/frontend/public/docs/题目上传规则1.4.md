# 题目上传规则与模板 1.4

适用平台：数海 MathSea。更新日期：2026-09-09。

本版统一10个TAG，采用内容初审和用户反馈流程，兼容旧版文件。教材目录以项目提供的《普通高中〈数学〉（共5册）课本目录（人教A版） - 知乎.pdf》为准。

## 一、准备文件与上传流程

1. 一道题一个UTF-8编码的 `.md` 文件。Windows换行和UTF-8 BOM均可识别。
2. 一张试卷一个文件夹，文件名建议与原始 `id` 相同。图片放在对应题目的同一文件夹，支持PNG、JPG/JPEG、GIF、WebP。
3. 后台“题目管理 → 批量导入”可以选择一张试卷目录，也可以选择包含多张试卷的年份目录。逐一确认完整试卷名称，必须区分年份、卷别、文理科；已有试卷选择已有记录。
4. 导入只创建草稿。初审只核对题干、答案、解析和配图。内容无误后审核发布；分类、难度、教材章节不要求在初审逐项确认。
5. `id` 是原始资料标识；网站显示的八位题号由系统在首次发布时生成，写MD时不要手工分配。

目录示例：

```text
2026/
  2026新高考Ⅱ卷/
    2026新高考Ⅱ卷T1.md
    2026新高考Ⅱ卷T2.md
    T2-题图.png
    T2-解析图.png
```

同目录的图片文件名应唯一，跨试卷同名图片会分别关联。建议先用少量题目验证排版和配图，再导入整批文件。

## 二、元数据格式

文件以两行独立的 `---` 包住元数据，每行一个 `字段:值`。字段值写在同一行，不要写YAML缩进列表、JSON数组或多行字符串，也不要给整个字段值加外层引号。多个知识点或章节使用英文逗号分隔。中英文冒号均兼容，推荐统一使用英文冒号。

| 字段 | 填写规则 |
|---|---|
| id | 原始资料标识，建议“年份＋来源＋原卷题号”，如2026新高考Ⅱ卷T2；可含中文。 |
| title | 题目标题，可省略；省略时使用id。不是数学正文。 |
| year | 四位年份，如2026。课本题、自编题或年份不明时填0000。 |
| source | 题目来源名称，见第三节。 |
| source_category | G高考、E其他正式考试、T课本、N其他。新文件建议明确填写，避免自动识别产生误判。 |
| question_type | 单选题、多选题、填空题、解答题，四选一。 |
| number | 试卷原题号，如T2或2。同一试卷必须唯一。非试卷题按资料集内固定序号1、2、3……编号，资料集作为单独目录确认。 |
| difficulty | D1～D7，不填写BLACK、WHITE。 |
| tags | 使用本版10个大类，如集合与逻辑,函数与导数；允许多个TAG。旧细标签自动归并，同义名称不重复创建。 |
| curriculum | 本版固定填写PEP-A-2019。表示本次核定的人教A版五册教材，不表示题目来源必须是课本。 |
| chapters | 做题必需的教材章节代码，如A11,A42；可留空，表示尚未标注。代码表见第四节。 |

`number:0` 只作为旧版兼容输入，不建议新文件继续使用：同一资料集多个0会触发题号冲突。`id` 相同不代表可以跨卷覆盖：系统按确认的试卷身份和原题号检查重复。

旧字段 `creator_uid`、`created_at`、`updated_at`、`problem_number` 可以保留，作为来源记录；它们不决定实际操作人、平台题号或平台时间。系统以登录管理员及实际保存、发布记录为准。不要在MD中填写密码、令牌等信息。

## 三、来源与平台题号

来源名称继续沿用1.2的约定：

- 高考：全国卷、全国卷Ⅰ、全国卷Ⅱ、全国卷Ⅲ、全国甲卷、全国乙卷、新高考Ⅰ卷、新高考Ⅱ卷；地方卷如北京卷、山东卷；大纲卷统一填写大纲卷。
- 2010年以前的历史资料可继续使用“2009年及更早的高考试卷”，但导入时必须确认具体试卷完整名称，以区分年份和文理科。
- 其他正式考试如自主招生、强基计划、高考适应性测试卷、高联，填写对应来源，并选择E。
- 课本题填写明确教材名称，如“人教A版必修第一册”，来源类别T。
- 自编练习、来源不明的模拟材料等选择N；模拟题是否属于正式考试按实际来源判断，不仅凭“模拟”二字决定类别。未填写类别时系统会尝试识别，请在后台复核。

网站题号是“来源字母＋题型字母＋六位全库流水号”：G/E/T/N，加C单选、M多选、F填空、S解答，再加000001～999999。各前缀共用同一个序列，例如GC000001、EC000002、NM000003。草稿不占号。后期更正来源类别或题型只改变前缀，六位流水号保留，旧链接仍可访问。

## 五、怎样标注章节

1. `tags` 使用标准大类名称；`chapters` 单独保存教材章节，两者不能混填。例如 `tags:集合与逻辑,函数与导数`，`chapters:A11,A42`。
2. 根据确认的解法勾选全部实质必需章节。不要只标难度最高的一章，也不要把无关章补进去。
3. 题面出现某个词不一定代表考查该章；纯粹作为书写约定的集合符号，不需要机械增加集合章。反之，必须做集合运算，就应标A11。
4. 不要求将每一道题都标上全部先修章节。标明这道题解法实际用到的章节；初中基础运算不在本版18章中单独编码。
5. 例如题目需要集合运算和导数，则填A11,A42。学生只学A11时不能进入“当前可做”；两章都学过时才可以。难度由D1～D7另行判断。
6. 多种解法第一版以管理员确认的解法为准。不要自动认为“存在不用导数的解法”就适合低年级，须人工核对。
7. 留空表示未标注；未知代码会提示错误，请修正后重试。不同章的相近名称不能互换：A23立体几何初步与A31空间向量、A25概率与A52随机变量需按实际知识区分。

所有MD导入的章节均为待确认，文件不能授予“已确认”状态。即使填写 `chapters_confirmed:true` 等字段，也不会跳过人工核对。后台在题目信息中确认章节并发布后，人工标注优先用于学习进度筛选。没有人工确认时，按TAG所覆盖的全部章节保守估计；该估计不会冒充人工确认。

未标注或未确认题目可以发布，并通过TAG映射参与学习进度粗略筛选。无TAG、含无法映射标签的题目暂不参与自动映射；章节专项仍只使用已确认章节。批量替换章节会清除原章节并重置为待确认；保存草稿、历史恢复均不直接改变公开题目的章节。

学生可选学期预设，再精确勾选已学章节；系统要求“题目所需章节全部已学”。章节专项表示“涉及任一所选章”，可以与已学范围叠加。学期预设由负责人维护，不是全国统一教学进度，不需要写入每道题的MD。

## 六、难度、正文、答案和配图

D1～D7依次对应RED、ORANGE、YELLOW、GREEN、CYAN、BLUE、PURPLE；BLACK、WHITE暂为保留值。平台保留1.2的六种试卷难度模板，管理员可以选择模板查看建议，建议不会自动覆盖原难度。未知卷型请人工复核。

元数据结束后分别写 `content:`、`answer:`、`solution:`。推荐三段都填写；没有可靠答案或解析时可以留空，严禁为凑齐字段编造内容。

- 中文文字直接写，行内公式使用 `$...$`，独立公式使用 `$$...$$`。
- 正文不要包在整个Markdown代码块中。无需将全部中文放入LaTeX；普通Markdown标题、表格和HTML不是本平台完整富文本排版协议，需以预览为准。
- 选择题建议各选项单独一行，避免把四个选项塞进一个超长公式；手机上超长公式会横向滚动。
- 普通中文使用宋体，英文数字使用Times New Roman，公式保留数学字体。材料段独立写 `:::material` 开始，独立一行 `:::` 结束，其中文字使用楷体。
- 图片文件名可以任意命名，不再要求与id相同。推荐用 `![题图](T2-题图.png)` 放在需要的位置；解析图放在solution段，答案图可放answer段。
- 旧格式 `img:{T2-题图.png}` 继续兼容，多个图片写作 `img:{图1.png}{图2.png}`，作为题干附图。已用Markdown引用的图片不需要再重复写进img段。
- 无附图写 `img:0`。不使用外部图片网址、绝对路径、`../` 路径或HTML标签。请把原图一起放入目录上传。
- 单张图片不超过10MB、MD不超过2MB；当前服务器整道题上传请求限制12MB。配图过大时压缩，或先导入文字再在工作台逐张补传。

材料示例：

```text
content:
:::material
某研究小组记录了一组数据……
:::
根据材料回答下列问题。
```

## 七、完整MD示例

以下示例可直接保存为 `示例卷T1.md`；在导入时作为自编练习资料集单独确认，不要归入真实高考试卷。

```markdown
---
id:示例卷T1
title:集合与导数综合题
year:0000
source:自编练习
source_category:N
question_type:填空题
number:T1
difficulty:D2
tags:集合与逻辑,函数与导数
curriculum:PEP-A-2019
chapters:A11,A42
---
content:
设 $f(x)=x^2-2x$，集合 $A=\{x\in\mathbb{R}\mid f'(x)>0\}$，$B=(-\infty,3)$，则 $A\cap B=$ ______。

answer:
$(1,3)$。

solution:
由 $f'(x)=2x-2>0$，得 $x>1$，故 $A=(1,+\infty)$。
所以 $A\cap B=(1,3)$。

img:0
```

## 八、重复导入与后期修改

- 同一试卷、同一原题号，文件及图片均未变化时跳过；内容变化时提示冲突，打开原草稿人工比较，不自动覆盖。
- 不要靠改id来替换已发布题目。进入“已发布题目 → 校对 / 修改”，原公开版本继续可见，新版审核发布后才替换。
- 可使用“保存并下一题”连续复核；Ctrl+S保存，Ctrl+Shift+S保存并下一题，macOS使用Command。
- 领取任务避免多人重复编辑；版本冲突时保留本地草稿并比较。历史记录可恢复成草稿，再走复核流程。
- 更改题干或解法后请重新核对章节。来源资料的旧标签只是线索，不能作为完整章节标注的保证。

## 十、标准TAG与学习进度映射

| TAG | 自动映射章节 |
|---|---|
| 集合与逻辑 | A11 |
| 函数与导数 | A13, A14, A42 |
| 三角与解三角形 | A15, A21 |
| 数列 | A41 |
| 不等式 | A12 |
| 平面向量 | A21 |
| 解析几何 | A32, A33 |
| 立体几何 | A23, A31 |
| 概率与统计 | A24, A25, A51, A52, A53 |
| 复数 | A22 |

一道题有多个TAG时，取所有对应章节的并集，必须全部已学才会入选。例如函数与导数覆盖A13、A14、A42，因此未学导数时会少选一部分普通函数题；人工确认精确章节后可改善这一点。TAG只代表知识范围，不能保证题目难度适合，也不能替代对解法的判断。

旧标签示例：集合→集合与逻辑；导数→函数与导数；双曲线、抛物线→解析几何；排列组合→概率与统计。未识别标签保留在原始文件和迁移记录中，不自动创建新TAG。初审不因此阻塞；整理后可在题目信息中解除自动映射限制。
