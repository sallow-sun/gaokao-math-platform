# 题目工作台开发说明

管理员当前操作流程以 [内容初审与反馈说明](../../frontend/public/docs/内容初审与反馈说明.md) 为准；题目 MD 以 [规则 1.4](../../frontend/public/docs/题目上传规则1.4.md) 为准，兼容 1.2、1.3。

批量导入仅创建草稿。初审直接看题干、答案、解析及配图，内容无误即发布；有疑问可转待修改，之后集中处理。初审不强制要求 TAG/难度/章节人工核对。已发布题目创建修订，正式发布前公开版本不变。

打开题目自动取得占用；保存检查版本号。当前 UI 已移除多选领取及批量改字段，后端 `/bulk` 接口保留兼容。不要重新在初审页面暴露这套旧操作。

反馈按题目分组，修改发布和解决选定反馈在同一事务完成；后来新增的反馈保持待处理。题目删除进入回收站，恢复和彻底删除由负责人操作。题号全局递增，不重用。

后端主要代码在 `admin/editorial/`、`feedback/`、`curriculum/`；集成验证位于 `EditorialIntegrationTest`。迁移只追加新版本，不修改已上线 V1～V11。更多入口见 [开发交接](../../docs/DEVELOPMENT.md)。
