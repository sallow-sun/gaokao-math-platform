# 自主组卷第一版

入口为 `/paper`，主导航“组卷”。前端沿用全站颜色、导航和数学渲染，后端复用题库查询；不新增数据库表或迁移。

## 用户操作

- 在左侧按题型、知识点、年份、来源、训练价值、教材章节及学习进度筛选；同一条件支持多选。
- “新题优先”按收录时间倒序。“随机排序”对全部符合条件的题目排序，翻页沿用同一个种子；“换一批”生成新的种子并回到第一页。
- 筛选栏复用题库组件，支持常用项、多选及完整条件弹窗；独立保留新题优先和随机排序。
- 拖动整张题卡（包括文字和公式）到右侧纸张，在插入位置松手。也可点“加入”，触屏可用添加及上移/下移按钮完成组卷。
- 纸张内可拖动排序，设置每题答题留白及另起一页。移除、排序、清空可撤销，最多保留 20 步。
- 本地草稿自动保存在当前浏览器，可刷新恢复；不跨设备同步。一份草稿最多 100 题，保存题干和配图引用，不保存答案、解析或个人学习状态。
- “预览打印”隐藏编辑控件；“打印 / 存为 PDF”打开浏览器打印对话框，可选择打印机或保存 PDF。建议保留页面指定尺寸、100% 比例，关闭浏览器额外页眉页脚。

## 排版参考及实现

参考用户提供的《如何制作一份高考数学原版试卷？ - 知乎.pdf》第 5～16 页。采用宋体与 Times New Roman 的字体顺序、五号正文（10.5 pt）、1.5 倍行距、黑体学科标题、全角题号点及选项自动四列/两列/一列布局。纸张支持 A4（210 × 297 mm）和 16 开（185 × 260 mm），页边距上下 20 mm、左右 22 mm，页脚显示页码。

浏览器字体与 KaTeX 公式字形可能与原文的 Word/MathType 排版略有差异；字体不从本机复制或打包发布。

`paperLayout.js` 安全渲染题干、识别独立的 A～D 选项、清理原题号及验证草稿结构。`PaperBuilderView.vue` 在实际纸张宽度下等待字体和图片加载、测量排版：普通题尽量整题同页；超过一页的题目依据文字行、公式、图片占用区域寻找分页空隙。单个超过整页高度的内容会缩放以保持完整。屏幕与打印共用同一组纸张和内容片段，打印使用 HTML/字体与图片，不将整页栅格化。

配图失败时给出提示并阻止打印；题库查询失败显示重试，不用原型题替代。切换条件会取消旧请求，已选题保留。草稿使用选题时的题干快照，但图片依然引用题库文件；这不是用于长期归档的完整试卷版本系统。

## API 与检查

`GET /api/v1/problems` 新增 `sort=random` 和 `seed` 参数，其他筛选及权限规则不变。`seed` 默认 `0`，后端最多取前 80 个字符，以绑定参数参与 `md5(id || ':' || seed)` 排序，并用 ID 作次级排序。相同种子在题库数据未变化时跨页稳定；题库新增、删除或筛选条件改变后结果集合可能变化。

前端单元测试覆盖内容保留、选项公式、草稿清理、分页边界；浏览器测试覆盖拖拽、筛选、随机种子、排序、留白、撤销、恢复、长题、配图、PDF、请求异常及手机布局。后端集成测试使用临时 PostgreSQL 验证稳定随机分页、换种子、新题排序和筛选/下架隔离。

执行 `npm run lint`、`npm test`、`npm run test:browser`、`npm run build`（frontend）及 `mvn verify`（backend）。发布按 `deploy/README.md`，后端与前端应一起更新。
