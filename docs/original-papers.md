# 原卷归集与核验版本

入口：管理后台 → 题目管理 → 原卷整理。批量导入时确认的试卷归属会自动形成待整理原卷，已有导入记录也可直接整理。

## 上传与重复题

- 同一次导入中，确认采用相同名称的新目录归入同一原卷。跨批次上传先提示同名候选，须确认关联已有试卷或单独新建。
- 名称比较统一全半角、空白与罗马数字；不依靠名称强行合并。年份、地区、卷别由上传者确认，可在原卷整理中补充。
- 同一原卷同一题号保持现有导入冲突保护，不覆盖旧题。彻底删除后可重新导入，旧的导入指纹不会阻挡。
- 整理界面提供疑似重复题候选：同题型且文本去空白、数字后相同。仅为保守的规则提示，不是全面的 OCR/语义查重；图片和公式需要人工对照。也可手填已有题号复用。
- 复用在原卷关联层生效，不复制新题、不覆盖题库内容，也不自动删除上传草稿。上传记录与贡献者仍保留；尚未审核的重复上传草稿仍可在原审核流程处理。

## 发布

1. 选择原卷，核对每项题序、分数，可排除重复项；题型按照现有打印引擎的单选、多选、填空、解答顺序排列。
2. 填写预期题数和总分。默认每题分值只是起点，必须对照原卷确认。
3. 保存整理草稿，查看保存时最终采用的题目与配图。未发布的题目须先审核，或者明确关联已经存在的题库题目。
4. 复核员或负责人填写核验范围/版本说明，勾选确认后发布。系统检查题数、总分、分值步长、重复题号与题型顺序。

发布保存独立题目内容和附件链接快照，标记“原卷已核验”。这表示管理员核对的范围，不自动保证答案解析已核验。已发布文件引用沿用现有共享试卷附件保留机制。

## 版本与并发

- 每次发布生成新的共享试卷 ID，原卷内部递增 v1、v2。旧版内容不变；数据库触发器阻止更改已发布原卷的内容与结构字段。
- 草稿保存使用乐观版本，发布对草稿行加锁并校验审核内容指纹；指纹包含题目工作稿、公开内容和配图，过期页面不能静默发布变更后的题目。
- 整理与发布操作记入审计日志。旧版可撤销认证或下架，但不能改写；修正内容应发布新版。
- 试卷库默认只显示最新的未下架版本；历史版本可在详情页访问。“我的”和“收藏”保留对应版本，评分、收藏按版本分别记录。
- 用户复制原卷到自己的组卷后可自由编辑，不影响已核验版本。

新增 V17 迁移与 `/api/v1/admin/original-papers` 接口，沿用后台认证及 CSRF 保护。此次不需要 OSS，也不改变尚未开通的 PDF 上传配置。
