# 内容初审与用户反馈

## 审核

进入题目工作台的“初审”，按试卷筛选后点击“开始 / 继续审核”。页面直接展示题干、答案、解析和配图。无需先核对TAG、难度或教材章节。

- 内容无误：通过并下一题。
- 有问题需要稍后处理：待修改并下一题，填写简短原因。
- 暂时拿不准：跳过，题目仍保留在队列中。
- 即时修改：编辑题目，选择正文、题目信息或配图；修改后发布。只有内容需要修改时才打开编辑区。
- 跳题或返回之前的题：展开“目录”。

负责人可在“初审”或“已发布”点击“批量删除”，勾选题目或选择当前页，再点击“删除所选”确认。切换分区、筛选或翻页会清空选择；取消选择即可回到日常审核。初审删除的是草稿，已有公开版本保持不变；已发布删除会下架题目。均可从“更多 → 回收站”恢复。草稿恢复后回到初审，不直接发布。删除当前正在审核的题目后，会继续打开下一道可处理的题目。

初审批量删除会检查版本和其他管理员占用；有冲突时整批不删除，请刷新列表后重新选择。仍在回收站的修订草稿需先恢复才能继续修改对应公开题目。

## 回收站彻底删除

负责人进入“更多 → 回收站”，点击“批量彻底删除”，勾选题目或选择当前页，再点击“彻底删除所选”。单题“彻底删除”使用同一个认证流程。

核对弹窗中的题目，请另一位正常使用的管理员亲自输入账号和密码，勾选不可恢复确认，再点击“认证并彻底删除”。不能使用当前操作人的账号认证；该认证仅用于本次所选题目，不切换登录账号，不保存密码。认证失败后需重新输入密码。

每次最多100题，当前页面最多40题；切换筛选、翻页或取消选择会清空选择。题目状态发生变化时整批不删除，需要刷新后重新选择并认证。彻底删除会清理正文、修订历史和不再被引用的配图，保留题号及操作审计，不能从回收站恢复。反馈快照和已有备份独立保留。只删除草稿时不会影响公开版本；如需再次修改公开题目，系统会从公开内容重新建立修订。

TAG统一为10个大类，旧标签自动归并。学习进度优先使用人工确认章节；没有确认时按TAG完整范围估计，可能少选。标签对应表见《题目上传规则1.4》。初审不需要操作章节选择器。

## 用户反馈

题目详情页点击“题目反馈”，登录后选择问题类型、描述具体问题，可附修改建议和一张截图。系统自动关联题号，并保留提交时的题目内容。每天最多20条，重复未处理反馈不重复创建。

个人主页的“我的反馈”可查看处理状态和说明。

## 处理反馈

审核人员进入“用户反馈”，按题目集中处理。支持待处理、待修改、已处理三个分区。

- 修改题目并解决：打开同一道题的编辑区，反馈内容显示在上方。修改后点击“发布修改并解决反馈”，题目发布和反馈解决一起完成；任何版本冲突都会阻止这次提交。
- 转待修改：填入说明，移入反馈的待修改分区。
- 标记已解决／无需修改：填写原因，用户可以看到结果。
- 负责人可暂时下架已确认有严重问题的题目，之后从回收站恢复。

处理只影响当时打开的反馈；后来新增的反馈仍保留待处理。多人处理时发生版本冲突，应返回反馈列表重新打开核对。反馈快照独立保留，用于核对问题和处理记录。
