# 内容初审与用户反馈

## 审核

进入题目工作台的“初审”，按试卷筛选后点击“开始 / 继续审核”。页面直接展示题干、答案、解析和配图。无需先核对TAG、难度或教材章节。

- 内容无误：通过并下一题。
- 有问题需要稍后处理：待修改并下一题，填写简短原因。
- 暂时拿不准：跳过，题目仍保留在队列中。
- 即时修改：编辑题目，选择正文、题目信息或配图；修改后发布。只有内容需要修改时才打开编辑区。
- 跳题或返回之前的题：展开“目录”。

TAG统一为10个大类，旧标签自动归并。学习进度优先使用人工确认章节；没有确认时按TAG完整范围估计，可能少选。标签对应表见《题目上传规则1.4》。初审不需要操作章节选择器。

## 用户反馈

题目详情页点击“题目反馈”，登录后选择问题类型、描述具体问题，可附修改建议和一张截图。系统自动关联题号，并保留提交时的题目内容。每天最多20条，重复未处理反馈不重复创建。

个人主页的“我的反馈”可查看处理状态和说明。

## 处理反馈

审核人员进入“用户反馈”，按题目集中处理。支持待处理、待修改、已处理三个分区。

- 修改题目并解决：打开同一道题的编辑区，反馈内容显示在上方。修改后点击“发布修改并解决反馈”，题目发布和反馈解决一起完成；任何版本冲突都会阻止这次提交。
- 转待修改：填入说明，移入反馈的待修改分区。
- 标记已解决／无需修改：填写原因，用户可以看到结果。
- 负责人可暂时下架已确认有严重问题的题目，之后从回收站恢复。

处理只影响当时打开的反馈；后来新增的反馈仍保留待处理。多人处理时发生版本冲突，应返回反馈列表重新打开核对。反馈快照独立保留，用于核对问题和处理记录。
