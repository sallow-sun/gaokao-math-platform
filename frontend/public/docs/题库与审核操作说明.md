# 题库与审核操作说明

## 题库

- TAG 的“更多”打开浮层，可搜索并选择标签。勾选“显示在筛选栏”可固定常用标签；固定不会自动筛选，偏好保存在当前浏览器。
- 题目自然展开，正文的多余空行仅在显示时压缩，不改动上传的原文。特别长的独立公式可横向滚动查看。
- 每道题保留独立的“打印”和“导出”入口。
- 个人中心的 TAG 统计可悬停、点击或键盘聚焦，查看各难度的题数。

## 连续审核

1. 在“待审核”选择试卷或搜索题目，点击“开始 / 继续审核”。系统记住此浏览器上次打开的题目；也可直接点击左侧题目。
2. 阅读预览，检查题干、答案、解析、配图以及必要章节。
3. 需要立即修正时点击“编辑题目”，在“正文 / 题目信息 / 配图”中切换；保存草稿不会改变公开版本。
4. 无误后点击底部“通过并下一题”。需要稍后处理的题目点击“待修改并下一题”，记录问题后移入“待修改”。
5. 在“待修改”集中修正，完成后回到待审核队列。切换队列会保留本次使用的筛选和页码。

## 删除与恢复（负责人）

- “已发布”中可以单题删除，也可以勾选后批量删除。题目先进入回收站，从公开题库隐藏，原题号、内容、图片和关联记录保留。
- 从“已发布 → 回收站”或“更多 → 回收站”进入，点击“恢复”即可恢复原公开题目及原审核状态。
- “彻底删除”需要准确输入题号。它清除题目正文、解析、相关审核历史及不再被其他题目使用的配图，不能从回收站恢复。题号不会重新分配，已有收藏、做题和题单关联保留删除占位，操作审计仍保留。
- 已进入回收站的题目不能通过旧的审核页面重新发布；恢复后请重新打开再编辑。

本次更新不改变题目 Markdown 格式，编写题目仍使用《题目上传规则1.3》。
