# TAG 与连续审核说明

本说明补充题目上传规则1.3；原有MD结构、图片规则、难度及章节编码继续有效。

## 写题时如何标注

`tags` 是考试知识分类，`chapters` 是解题必需的教材章节，两者分别填写。例如：

```text
tags:双曲线,导数
curriculum:PEP-A-2019
chapters:A33,A42
```

双曲线隶属于圆锥曲线，圆锥曲线隶属于解析几何。填写最具体且相关的标签即可，不需要同时填写父标签。综合题可以写多个标签。

选择解析几何会包含椭圆、双曲线、抛物线等细分题；多选TAG按“涉及任一所选标签”查询。学习进度则要求题目所需章节全部已学。两者可以叠加。

常用分类：集合与逻辑、函数、解析几何、立体几何、三角函数、数列、概率与统计、平面向量、不等式、复数。完整目录以题库TAG“更多”及后台知识标签选项为准。

已有别名会归一化，例如“解几”归为“解析几何”，“集合的运算”归为“集合”。旧题无需批量重写。新文件建议直接使用规范名称。

大模型生成的新名称可以随MD进入待审核；发布前须由负责人核对并在编辑区创建，或替换为已有标签。不得仅凭题干出现的词语判断标签或所需章节。

## 人工复审一次即可

1. 批量导入MD和配图后，题目进入待审核。格式错误仍留在导入结果中处理。
2. 打开题目，检查题干、图片、答案、解析、TAG、难度和所需知识；章节须人工确认。
3. 无误则点击“通过并下一题”，直接发布。仅具有复核或负责人权限的人员可以通过。
4. 发现问题，点击“待修改并下一题”，选择问题类型，可补充备注。题目移入待修改区。
5. 在待修改区按答案、解析、图片、排版、标签等类型集中修正。“保存草稿”仍留在该区；“修改完成并下一题”才送回待审核。

已发布题目集中展示在已发布区。修订先保存工作副本，审核通过后才更新线上题目。无需另设一轮初校，也不会在导入时自动公开。

## 连续操作与协作

预览为默认视图，点击“编辑题目”展开表单。所需知识默认显示摘要，点击修改展开目录。历史版本、原始MD及其他管理设置按需展开。

左侧队列与右侧题目可以分别滚动；底部审核按钮保持在工作区底部。操作成功后接续下一题，保存失败不会跳过当前题。Ctrl+S保存，离开未保存题目时会提醒。

打开题目会自动占用处理任务。其他管理员正在处理时会提示冲突；切换题目后释放，离线任务20分钟后可重新取得。保存仍检查版本，避免覆盖他人的更新。
