# Mathverse 前端

当前版本包含 Mathverse 高中数学社区主页、Knowledge Galaxy 知识星系，以及独立的入场页概念稿。Mathverse 暂时作为项目代号，最终品牌名称仍待确定。项目暂时使用原生 HTML、CSS 和 JavaScript，方便团队成员并行开发不同页面。

## 目录说明

- `index.html`：网站根入口，直接进入主页，不再单独播放入场界面。
- `pages/home.html`：主页结构与演示内容。
- `pages/galaxy.html`：Knowledge Galaxy 知识星系交互原型。
- `prototypes/entrance-concept.html`：独立入场页概念稿，仅用于评审，不接管正式入口。
- `styles/`：全局设计变量、基础样式、布局、通用组件和页面专属样式。
- `scripts/`：页面交互、主页黑洞动画和知识星系逻辑。

## 当前交互

- 主页右上角集成轻量版黑洞入场动画，并支持响应式侧栏、搜索演示、随机探索、个人计时表和今日计划。
- 独立入场页概念稿支持鼠标点击、触摸或任意非修饰键进入主页。
- 个人计时表与今日计划目前保存在用户当前设备中，账号同步将在后续阶段接入。
- 知识星系支持分层缩放、个人进度视图、节点检索、学习深度演示、个人标签和全屏沉浸探索。
- 题库、题单、整卷、题目详情、账号与知识地图暂时展示为预留入口，后续可独立开发。

## 协作约定

新增页面放在 `pages/`；页面专属样式放在 `styles/pages/`；页面脚本放在 `scripts/pages/`。通用颜色和尺寸优先复用 `styles/tokens.css` 中的变量。

主页黑洞和独立入场页通过 CDN 加载 Three.js。团队联调时建议使用本地静态服务器打开 `index.html`，不要只复制某一个 HTML 文件单独运行。
